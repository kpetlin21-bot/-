# Миграция: «Учет сделок 2026» + «без рыб и НК» → единый `ЖУРНАЛ`

## Результат миграции (автоматически)

| Показатель | Значение |
|------------|----------|
| Строк в `bez_ryb_NK` | 305 |
| Строк в `Uchet_sdelok 2026` | 182 |
| Пересечений (одинаковая сделка) | 80 |
| Уникальных только в «Учет 2026» | 102 |
| **Итого в `ЖУРНАЛ`** | **377** (без пустых строк) |
| Оплачено | 44 |
| Частично | 1 |
| Не оплачено | 332 |

Файл для импорта: `finance/output/MASTER_JOURNAL_migrated.csv`

## Правило слияния (80 пересечений)

1. **Оплата** (`Осталось получить`, `S`) — из **`без рыб и НК`** (там 45 оплат и 1 частичная).
2. **План поступления, статус акта, УПД** — из **`Учет сделок 2026`**, если в `bez_ryb` поле пустое.
3. **102 строки** только в «Учет 2026» (в основном ЖК Рыбацкое, Курортный, периоды 2026+) — добавляются целиком.
4. Пустые строки (29 шт. в хвосте `bez_ryb`) — **отбрасываются**.

Конфликты по 80 ключам: `finance/output/MIGRATION_CONFLICTS.json` (в основном: в `bez_ryb` нет даты плана, в `Uchet 2026` — есть).

## Пошаговая установка в Google Sheets

### Шаг 1. Новый лист `ЖУРНАЛ`

1. Создайте лист **`ЖУРНАЛ`**.
2. Файл → Импорт → Загрузить `MASTER_JOURNAL_migrated.csv` → **Заменить данные** на листе `ЖУРНАЛ`.
3. Добавьте формулы из `FORMULA_SCHEMA.md` (колонки AJ–AM).

### Шаг 2. Обновить `Справочник`

Добавьте колонку **F: Регион** для каждого ЖК (столбец E):

| E | F |
|---|---|
| ЖК Астрид | Санкт-Петербург |
| ЖК Курортный | Санкт-Петербург |
| ЖК Новое К | Санкт-Петербург |
| ЖК Космонавтов 11 | Екатеринбург |
| ЖК Астон.Движение (Пех) | Казань |
| … | … |

Исправьте клиента: `ООО АПРИ КОМФОРТ ЕКАТЕРИНБУРГ` (убрать zero-width пробел).

### Шаг 3. Заменить производные листы формулами

| Старый лист | Действие |
|-------------|----------|
| `ТЛ (2026) (ФАКТ)` | Формула QUERY из `ЖУРНАЛ` (см. FORMULA_SCHEMA) |
| `ДЗ на 01.03`, `ДЗ на 01.04` | Удалить / архив; заменить листом `ДЗ` = FILTER |
| `ИМПОРТ ДЗ *` | Больше не нужны |
| `без рыб и НК` | Переименовать в `_АРХИВ_bez_ryb` и скрыть |
| `Учет сделок 2026 (ФАКТ)` | Переименовать в `_АРХИВ_uchet_2026` и скрыть |
| `Для факта (ДЛЯ РРАСЧЕТА ВЫВОДА)` | Удалить (дубль, расходится на ~36 млн) |
| `Свод в разрезе ЖК` | Пересобрать QUERY (см. ниже) |

### Шаг 4. Починить свод по ЖК

```gs
=QUERY(
  ЖУРНАЛ!A:K;
  "select A, E, sum(K) where A is not null group by A, E pivot W label sum(K) 'Сумма'";
  0
)
```

`W` — месяц окончания работ (или `Y` — месяц планового поступления).

### Шаг 5. Создать `ДАШБОРД` и `КАЛЕНДАРЬ_ДС`

По формулам из `FORMULA_SCHEMA.md`.
