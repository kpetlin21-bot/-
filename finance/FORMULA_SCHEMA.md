# CleanSyst Finance — схема формул (Google Sheets)

Книга: **CleanSyst Finance 2026** (единая).  
Логика оплаты: **`S` «Осталось получить» = 0** → оплачено; **> 0** → не оплачено или частично.

## Карта колонок листа `ЖУРНАЛ`

| Кол | Поле | Ввод |
|-----|------|------|
| A | Навзание проекта | да |
| B | Клиент | да |
| C | Менеджер | справочник |
| D | Отсрочка | справочник |
| E | Статья ОПиУ | справочник |
| F | Статья ДДС | справочник |
| G | Начислено с НДС | да |
| H | Наличие НДС | 5% |
| I | Сумма НДС | формула |
| J | Начислено без НДС | формула |
| K | ИТОГО, реализация за минусом штрафа | формула/ввод |
| P | УДЕРЖАНИЯ, штрафы | да |
| S | **Осталось получить по проекту** | **да (статус оплаты)** |
| X | Дата планового поступления ДС | да |
| AH | статус акта | справочник |
| **AJ** | **Оплачено (расчёт)** | формула |
| **AK** | **Статус оплаты** | формула |
| **AL** | **Регион** | формула |
| **AM** | **Дата для календаря** | формула |

---

## Лист `ЖУРНАЛ` — формулы (строка 2, протянуть вниз)

```gs
// I2 — НДС 5%
=ЕСЛИ(H2="5%"; G2/1,05*0,05; 0)

// J2 — без НДС
=G2-I2

// K2 — итого после штрафа (если штраф вводится вручную)
=G2-P2

// AJ2 — оплачено
=K2-S2

// AK2 — статус оплаты
=ЕСЛИ(S2=0; "Оплачено"; ЕСЛИ(S2<K2; "Частично"; "Не оплачено"))

// AL2 — регион из справочника по ЖК (столбец E → регион в F)
=ЕСЛИОШИБКА(ВПР(A2; Справочник!$E:$G; 2; ЛОЖЬ); "Санкт-Петербург")

// AM2 — дата в календарь только если есть дебиторка
=ЕСЛИ(S2>0; X2; "")
```

**Проверка частичной оплаты (пример):** ЖК Космонавтов 11 — K=1 791 676,56 / S=341 676,56 → AJ=1 450 000 / AK=«Частично».

## Лист `ДАШБОРД`

Ячейки (пример расположения):

```gs
// B2 — остаток дебиторки (все регионы)
=СУММ(ЖУРНАЛ!S:S)

// B3 — оплачено YTD
=СУММ(ЖУРНАЛ!AJ:AJ)

// B4 — начислено YTD
=СУММ(ЖУРНАЛ!K:K)

// B5 — просрочка (>0 дебиторки и дата плана < сегодня)
=СУММЕСЛИМН(ЖУРНАЛ!S:S; ">0"; ЖУРНАЛ!X:X; "<"&СЕГОДНЯ())

// Дебиторка по регионам (таблица H2:I5)
=СУММЕСЛИ(ЖУРНАЛ!S:S; ЖУРНАЛ!AL:AL; H2; ЖУРНАЛ!AK:AK; "<>Оплачено")

// Выручка по месяцам (план поступлений) — QUERY
=QUERY(ЖУРНАЛ!AL:AM; "select AL, sum(K) where AM is not null group by AL label sum(K) ''"; 0)

// Топ-5 ЖК по дебиторке
=QUERY(ЖУРНАЛ!A:S; "select A, sum(S) where S>0 group by A order by sum(S) desc limit 5 label sum(S) 'Дебиторка'"; 0)
```

**KPI по статусу оплаты:**

```gs
=СЧЁТЕСЛИ(ЖУРНАЛ!AK:AK; "Оплачено")
=СЧЁТЕСЛИ(ЖУРНАЛ!AK:AK; "Частично")
=СЧЁТЕСЛИ(ЖУРНАЛ!AK:AK; "Не оплачено")
```

## Лист `ДЗ` (автоматически, без ручных срезов)

Строка 1 — заголовки как в `ЖУРНАЛ`. Строка 2:

```gs
=FILTER(ЖУРНАЛ!A:AK; ЖУРНАЛ!S:S>0)
```

Сортировка по просрочке (вспомогательный столбец `AN` на `ДЗ`):

```gs
=ЕСЛИ(X2<СЕГОДНЯ(); "Просрочено"; "В срок")
```

## Лист `КАЛЕНДАРЬ_ДС` (поступления, 90 дней)

### Таблица плановых поступлений

```gs
// A2 — только будущие/текущие неоплаченные
=FILTER(
  {ЖУРНАЛ!AM:AM \ ЖУРНАЛ!A:A \ ЖУРНАЛ!B:B \ ЖУРНАЛ!F:F \ ЖУРНАЛ!AL:AL \ ЖУРНАЛ!S:S};
  ЖУРНАЛ!S:S>0;
  ЖУРНАЛ!AM:AM>=СЕГОДНЯ();
  ЖУРНАЛ!AM:AM<=СЕГОДНЯ()+90
)
```

Заголовки блока: `Дата | ЖК | Клиент | Статья ДДС | Регион | Сумма`.

### Накопительный остаток (упрощённо, только приток)

На листе `КАЛЕНДАРЬ_ДС`, столбец G «Накопительно»:

```gs
// G2, после сортировки по дате (A)
=СУММ($F$2:F2)
```

`F` — сумма поступления (= `S` из журнала).

### Свод по неделям

```gs
=QUERY(A:F; "select sum(F) group by week(A) label sum(F) 'Поступления'"; 0)
```

## Лист `БЮДЖЕТ_ФАКТ` (один, без дубля)

Строки — статьи ДДС, столбцы B–M — месяцы 1–12.

```gs
// B2 — факт поступлений ОД за январь (по дате плана X, только оплаченные+неоплаченные)
=СУММЕСЛИМН(
  ЖУРНАЛ!K:K;
  ЖУРНАЛ!F:F; "Поступление Клининг (ОД)";
  ЖУРНАЛ!Y:Y; 1
)

// Альтернатива — по фактической оплате (если позже добавите дату факта в колонку AO):
=СУММЕСЛИМН(ЖУРНАЛ!AJ:AJ; ЖУРНАЛ!AO:AO; ">="&ДАТА(2026;1;1); ЖУРНАЛ!AO:AO; "<="&ДАТА(2026;1;31))
```

Отклонение:

```gs
=Факт!B2-Бюджет!B2
```

=QUERY(

## Резерв налогов (добавить лист `НАЛОГИ`)

УСН 6% + НДС 5%:

```gs
// База УСН (доход без НДС, упрощённо)
=СУММ(ЖУРНАЛ!J:J)

// УСН 6% за квартал
=СУММЕСЛИМН(ЖУРНАЛ!J:J; ЖУРНАЛ!X:X; ">="&Q2; ЖУРНАЛ!X:X; "<="&R2) * 0,06

// НДС к уплате за квартал (начисленный)
=СУММЕСЛИМН(ЖУРНАЛ!I:I; ЖУРНАЛ!X:X; ">="&Q2; ЖУРНАЛ!X:X; "<="&R2)
```

Даты Q2/R2 — начало/конец квартала. Строки добавить в `КАЛЕНДАРЬ_ДС` как расходные события (25‑е после квартала).

## Условное форматирование `ЖУРНАЛ`

| Диапазон | Условие | Цвет |
|----------|---------|------|
| AK | «Оплачено» | зелёный |
| AK | «Частично» | жёлтый |
| AK | «Не оплачено» | белый |
| S + X | S>0 и X<СЕГОДНЯ() | красный (просрочка) |
| AH | «отказ» | красный |
